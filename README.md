# Rishabh Yadav - Personal Portfolio

A modern, responsive personal portfolio website built to showcase my projects, skills, education, and achievements as a Software Developer specialized in AI and ML.

## 🌐 Live Demo

**Deployed via Netlify:** [https://portfolio-rishabhy.netlify.app/](https://portfolio-rishabhy.netlify.app/)

## ✨ Features

- **Modern Design:** Clean, dark-themed UI with glassmorphism effects and smooth gradients.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop viewing.
- **Interactive:** Scroll animations, hover effects, and a smooth-scrolling navigation bar.
- **Project Showcase:** Detailed cards for highlighted projects with technology stack tags.
- **Skill Overview:** Categorized technical skills with visual indicators.
- **Contact Form:** Clean UI for getting in touch.

## 🛠️ Tech Stack

- **Framework:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React & React Icons
- **Animations:** Framer Motion

## 🚀 Running Locally

To run this project on your local machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/YadavRishabh002/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   This will start the server, typically at `http://localhost:5173/`.
